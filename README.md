# Aniimo Overlay — 배포

애니모(Aniimo) PC 버전 위에 띄우는 **비공식** 보조 오버레이입니다. 속성 상성, 도감(진화·특성·스킬·홈 능력·출현 방식), 지도(출현 지점·마커), 홈랜드 생산 계산기, 포획 확률 계산기, 파티 조합 추천, 퀘스트 도우미를 게임 화면 위에서 바로 봅니다.

## 다운로드
최신 버전: [Releases](https://github.com/BabyShark10/aniimo-overlay-releases/releases/latest) 에서 `AniimoOverlay.exe` 하나만 받으면 됩니다. 설치 없음.

- 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다 (코드 서명 없음). "추가 정보 → 실행"으로 진행하세요. 이후 업데이트는 프로그램 안에서 자동으로 이루어지며 경고가 뜨지 않습니다.
- 프로그램은 10분마다 이 저장소의 `latest.json` 을 확인해 새 버전을 알려주고, 트레이 메뉴 "업데이트 확인"으로 설치합니다.

## 사용
1. 게임을 실행합니다 (기본 화면 모드인 "테두리 없는 전체 창"이면 됩니다).
2. `AniimoOverlay.exe` 를 실행하면 시작 화면이 잠깐 보인 뒤 트레이 아이콘이 생기고, 게임 화면 상단에 작은 **툴바**가 나타납니다.
3. 툴바의 **상성** / **도감** / **홈랜드** / **포획** / **지도** / **파티** / **퀘스트** 버튼으로 패널을 켜고 끕니다. **설정**에서 배경 투명도·크기·단축키(기본 Alt+Q 표시/숨김, Alt+D 도감, Alt+P 파티)를 바꾸고, **≡** 에서 업데이트 확인·종료.
4. 패널은 마우스로 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다.
5. 종료: 트레이 아이콘 우클릭 → 종료.

## 홈랜드 생산 계산기
보유한 시설(밭·숲지·광산·가공 시설 등)의 개수와 레벨, 모듈 레벨을 넣고 [계산]을 누르면 어느 시설이 무엇을 만들어야 코인(또는 새싹 티켓) 수익이 가장 큰지, 시간당 수익, 목표 금액까지 걸리는 시간, 필요한 씨앗 수를 알려줍니다. 나무 블록·광물 모래를 먼저 확보하는 옵션도 있습니다.

> **참고**: 생산 시간·판매가·레시피는 게임 클라이언트의 데이터 표 기준이며 패널 상단에 데이터 버전을 표시합니다. 작업 시간은 시설당 애니모 1마리(입력한 홈 능력 레벨)로 추정하고 환경 건물 범위는 근사 계산이라 실제 배치와 조금 다를 수 있습니다. 게임 업데이트 후 수치가 바뀌면 데이터를 갱신합니다.

## 포획 확률 계산기
구역·단계·레벨 차·애니팟·상황(전투 외/전투 중/전투 불능)·HP·특수 상태를 고르면 최종 포획 확률과 계수별 내역을 보여줍니다. 수치는 게임 공식 안내([확률 공식](https://www.aniimo.com/ko/formula-multipliers))를 그대로 씁니다.

## 도감
이름(옛 이름도 됨)이나 번호로 검색하고, 속성·출현 지역·역할·홈 능력으로 걸러 볼 수 있습니다. 형태·진화 조건·출현 지역과 시간대·날씨, 설명·특성·스킬·행동 능력·홈 능력을 보여 주며 이 정보는 프로그램에 들어 있어 오프라인에서도 됩니다. 전신 이미지만 보는 항목을 그때 공식 CDN 에서 받아 저장합니다.

## 지도
산들바람 평원 지도 위에 애니모별 출현 지점(인게임 도감 서식지 기준)과 보물 상자·애니모 알·애니팟·보스·채집 등 마커를 보여줍니다. 오른쪽 열에서 마커 종류를 켜고 끄고, 상자·알처럼 한 번 얻는 것은 마커를 클릭해 완료 표시(반투명)하거나 숨길 수 있습니다. 구역을 클릭하면 그곳에 나오는 애니모 목록(시간대·날씨 조건 배지 포함)이 나오고, 애니모를 고르면 출현 지점이 표시됩니다. 썸네일에 마우스를 올리면 출현 조건과 **출현 방식**(출현 지점 수, 그 구역 날씨일 때만, 부숴야 나오는 오브젝트, NPC 대전 전용 등)이 보입니다. 완료 기록은 내 PC(`%LOCALAPPDATA%\AniimoOverlay`)에만 저장됩니다.

## 파티 조합
내 애니모(로스터)를 넣고 상대(이름 검색·속성·이미지 선택, 최대 4마리)를 고르면, 정한 역할 우선도(딜·격파·힐·서포터·에너지)와 성향(공격/밸런스/수비)에 맞춰 상성 구멍이 없는 4마리를 추천합니다. 어떤 상대 공격을 1.6배로 받는지 경고로 보여 줍니다.

## 퀘스트 도우미
에이델·아스트라 퀘스트를 분류별로 보여 주고, 퀘스트를 누르면 선행/후속 연결, 지도에 번호로 찍은 위치 그림, 번호 붙은 단계 설명이 나옵니다. 필요한 애니모·아이템·조건은 노란색으로 강조되고, 완료 표시와 완료 숨기기가 됩니다. 안내가 실제와 다르면 패널의 **버그 제보** 버튼으로 알려 주세요.

## 안전
- 게임 프로세스에 접근하지 않습니다. 메모리 읽기, 인젝션, 후킹, 자동 조작이 없습니다. 별도의 투명 창을 게임 창 위에 얹는 방식입니다.
- 이 동작 방식과 공식 위키 이미지 표시에 대해 Aniimo 고객지원에 문의해, 현재 방식은 별도의 문제가 없다는 답변을 받았습니다 (2026-09-16, 아래 "개발사 확인"). 제3자 프로그램 정책이 바뀌면 공식 공지를 따릅니다.

## 개발사 확인 (2026-09-16)
출시 전, 프로그램의 동작 방식과 공식 위키 이미지 사용에 대해 Aniimo 고객지원(support@aniimo.com)에 동작 영상과 함께 문의했고, 다음 답변을 받았습니다.

> 현재 전달해 주신 설명과 같이 게임 프로세스나 메모리를 읽거나 수정하지 않고, DLL 인젝션, Hook, 매크로, 게임 파일 수정, 화면 캡처 또는 통신 가로채기 등의 기능 없이 정보를 표시하는 방식이라면 별도의 문제는 없는 것으로 확인되었습니다.
>
> 공식 Aniimo Wiki의 이미지를 필요할 때 불러와 무료 및 비상업적 정보 제공 목적으로 Overlay 내에 표시하는 현재의 사용 방식 역시 별도의 문제는 없는 것으로 확인되었습니다.
>
> 추후 제3자 프로그램과 관련된 정책이나 이용 기준에 변경 사항이 있을 경우 Aniimo 공식 채널을 통해 안내될 예정이오니 관련 공지를 참고해 주시기 바랍니다.

이 확인은 위에 적은 동작 방식(메모리 접근·인젝션·후킹·매크로·파일 수정·화면 캡처·통신 가로채기 없음)에 대한 것입니다. 프로그램은 이 범위를 벗어나는 기능을 추가하지 않으며, 정책이 바뀌면 공식 공지를 따릅니다.
- 익명 사용 통계: 설치 때 만든 무작위 ID, 프로그램 버전, 실행/업데이트 여부, 오류가 났을 때의 오류 코드(예: AO-3004)만 전송해 사용자 수와 오류 빈도를 파악합니다. 이름·이메일·IP·게임 정보·개인 파일 경로는 보내지 않습니다.
- 실행 파일은 이 저장소의 Releases 에서만 배포됩니다. 다른 곳에서 받은 파일은 신뢰하지 마세요. `latest.json` 의 sha256 으로 검증할 수 있습니다.

## 문제 신고 · 건의
[Issues](https://github.com/BabyShark10/aniimo-overlay-releases/issues/new/choose) 에서 **"오류 / 문제 신고"** 또는 **"건의 / 기능 요청"** 을 골라 올려 주세요. 프로그램 안에서는 트레이·≡ 메뉴의 "문제 신고 · 건의" 나 정보 창의 버튼으로 바로 갈 수 있습니다. 있으면 좋겠다 싶은 기능, 불편한 점, 잘못된 데이터(상성·도감·홈랜드 수치)도 모두 환영합니다.

오류나 갑작스런 종료를 신고할 때는 아래 내용이 함께 있으면 원인을 훨씬 빨리 찾을 수 있습니다.

1. **오류 코드**: 안내 창에 `(오류 코드 AO-xxxx)` 가 보였다면 그 코드. 코드가 안 보였어도 괜찮습니다.
2. **로그 파일**: 트레이 아이콘 우클릭 → **로그 폴더 열기** 를 누르면 폴더가 열립니다. 그 안의 `log.txt` 를 통째로 첨부해 주세요 (마지막 부분만 붙여 넣어도 됩니다).
   - 직접 찾아가려면 탐색기 주소창에 `%LOCALAPPDATA%\AniimoOverlay` 를 입력합니다. 보통 `C:\Users\<사용자 이름>\AppData\Local\AniimoOverlay` 입니다.
   - 로그에는 게임·개인 정보가 들어가지 않지만, 파일 경로에 Windows 사용자 이름이 보일 수 있으니 신경 쓰이면 그 부분만 지우고 올려 주세요.
3. **프로그램 버전**: 툴바 ≡ → 정보, 또는 트레이 아이콘에 마우스를 올리면 나오는 `v1.x.x`. (v1.0.0 부터 이전 0.1.x 버전은 지원하지 않으며, 실행하면 새 버전 안내가 뜹니다)
4. **무엇을 하다가 그랬는지**: 예) "도감에서 화르랑을 검색하고 진화 그림을 눌렀을 때 꺼짐". 게임 화면 모드(전체 창/창 모드)와 모니터 구성(개수, 배율)도 도움이 됩니다.
5. **스크린샷**: 오류 창이나 이상하게 그려진 화면이 있으면 캡처.

프로그램이 갑자기 꺼졌다면 다음 실행 때 원인 코드가 자동으로 익명 보고되므로, 한 번 더 실행해 주시면 도움이 됩니다.
