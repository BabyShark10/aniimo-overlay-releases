# Aniimo Overlay — 배포

애니모(Aniimo) PC 버전 위에 띄우는 **비공식** 보조 오버레이입니다. 속성 상성, 도감(진화·특성·스킬·홈 능력), 홈랜드 생산 계산기, 포획 확률 계산기를 게임 화면 위에서 바로 봅니다.

## 다운로드
최신 버전: [Releases](https://github.com/BabyShark10/aniimo-overlay-releases/releases/latest) 에서 `AniimoOverlay.exe` 하나만 받으면 됩니다. 설치 없음.

- 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다 (코드 서명 없음). "추가 정보 → 실행"으로 진행하세요. 이후 업데이트는 프로그램 안에서 자동으로 이루어지며 경고가 뜨지 않습니다.
- 프로그램은 6시간마다 이 저장소의 `latest.json` 을 확인해 새 버전을 알려주고, 트레이 메뉴 "업데이트 확인"으로 설치합니다.

## 사용
1. 게임을 실행합니다 (기본 화면 모드인 "테두리 없는 전체 창"이면 됩니다).
2. `AniimoOverlay.exe` 를 실행하면 트레이 아이콘이 생기고, 게임 화면 상단에 작은 **툴바**가 나타납니다.
3. 툴바의 **상성** / **도감** / **홈랜드** / **포획** 버튼으로 패널을 켜고 끕니다. **설정**에서 배경 투명도·크기를 바꾸고, **≡** 에서 업데이트 확인·종료.
4. 패널은 마우스로 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다.
5. 종료: 트레이 아이콘 우클릭 → 종료.

## 홈랜드 생산 계산기
보유한 시설(밭·숲지·광산·가공 시설 등)의 개수와 레벨, 모듈 레벨을 넣고 [계산]을 누르면 어느 시설이 무엇을 만들어야 코인(또는 새싹 티켓) 수익이 가장 큰지, 시간당 수익, 목표 금액까지 걸리는 시간, 필요한 씨앗 수를 알려줍니다. 나무 블록·광물 모래를 먼저 확보하는 옵션도 있습니다.

> **주의**: 계산에 쓰는 생산 시간·판매가·레시피는 **베타 기준 커뮤니티 자료**([Aniimax](https://github.com/spacetot/aniimax), MIT)입니다. 정식 출시 후 수치가 달라질 수 있으니 참고용으로만 보고, 실제 게임에서 확인해 주세요. 확인되는 대로 데이터를 갱신합니다.

## 포획 확률 계산기
구역·단계·레벨 차·애니팟·상황(전투 외/전투 중/전투 불능)·HP·특수 상태를 고르면 최종 포획 확률과 계수별 내역을 보여줍니다. 수치는 게임 공식 안내([확률 공식](https://www.aniimo.com/ko/formula-multipliers))를 그대로 씁니다.

## 도감
이름(옛 이름도 됨)이나 번호로 검색하면 형태·진화·출현 지역과 함께 공식 위키의 설명·탐사 스킬·특성·스킬·홈 능력·공명 단계 육성 정보를 보여줍니다. 위키 정보와 이미지는 보는 항목만 그때 받아 저장합니다.

## 안전
- 게임 프로세스에 접근하지 않습니다. 메모리 읽기, 인젝션, 후킹, 자동 조작이 없습니다. 별도의 투명 창을 게임 창 위에 얹는 방식입니다.
- 익명 사용 통계: 설치 때 만든 무작위 ID, 프로그램 버전, 실행/업데이트 여부, 오류가 났을 때의 오류 코드(예: AO-3004)만 전송해 사용자 수와 오류 빈도를 파악합니다. 이름·이메일·IP·게임 정보·개인 파일 경로는 보내지 않습니다.
- 실행 파일은 이 저장소의 Releases 에서만 배포됩니다. 다른 곳에서 받은 파일은 신뢰하지 마세요. `latest.json` 의 sha256 으로 검증할 수 있습니다.

## 문제 신고 · 건의
[Issues](https://github.com/BabyShark10/aniimo-overlay-releases/issues/new/choose) 에서 **"오류 / 문제 신고"** 또는 **"건의 / 기능 요청"** 을 골라 올려 주세요. 있으면 좋겠다 싶은 기능, 불편한 점, 잘못된 데이터(상성·도감·홈랜드 수치)도 모두 환영합니다.

오류나 갑작스런 종료를 신고할 때는 아래 내용이 함께 있으면 원인을 훨씬 빨리 찾을 수 있습니다.

1. **오류 코드**: 안내 창에 `(오류 코드 AO-xxxx)` 가 보였다면 그 코드. 코드가 안 보였어도 괜찮습니다.
2. **로그 파일**: 트레이 아이콘 우클릭 → **로그 폴더 열기** 를 누르면 폴더가 열립니다. 그 안의 `log.txt` 를 통째로 첨부해 주세요 (마지막 부분만 붙여 넣어도 됩니다).
   - 직접 찾아가려면 탐색기 주소창에 `%LOCALAPPDATA%\AniimoOverlay` 를 입력합니다. 보통 `C:\Users\<사용자 이름>\AppData\Local\AniimoOverlay` 입니다.
   - 로그에는 게임·개인 정보가 들어가지 않지만, 파일 경로에 Windows 사용자 이름이 보일 수 있으니 신경 쓰이면 그 부분만 지우고 올려 주세요.
3. **프로그램 버전**: 툴바 ≡ → 정보, 또는 트레이 아이콘에 마우스를 올리면 나오는 `v0.x.x`.
4. **무엇을 하다가 그랬는지**: 예) "도감에서 화르랑을 검색하고 진화 그림을 눌렀을 때 꺼짐". 게임 화면 모드(전체 창/창 모드)와 모니터 구성(개수, 배율)도 도움이 됩니다.
5. **스크린샷**: 오류 창이나 이상하게 그려진 화면이 있으면 캡처.

프로그램이 갑자기 꺼졌다면 다음 실행 때 원인 코드가 자동으로 익명 보고되므로, 한 번 더 실행해 주시면 도움이 됩니다.

## 고지
Aniimo 는 Pawprint Studio / Kingsglory 의 상표이며 이 프로젝트는 게임사와 무관합니다.
